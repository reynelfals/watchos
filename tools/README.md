# Tools

Helper scripts for icons, WRGB conversion, SoftAP Squish push, and flash helpers.

The full Squish SD library staging tree (`squish_sd_stage`, thousands of WRGB thumbs) is **not** shipped in this public repo — use `push_squish_sd.py` / `data/apps/squish_id/IMAGES.md` with your own image set. A small sample set ships under `data/apps/squish_id/img/`.
