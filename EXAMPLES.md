# Example apps in this public tree

Curated for Waveshare ESP32-S3 Touch AMOLED 2.06 + WatchOS host.

| App | Why it's here |
|-----|----------------|
| `_example_hello` | Minimal Lua app skeleton |
| `counter` | Tiny interactive demo |
| `tilt_maze` | IMU / tilt gameplay |
| `waterfall` | Live mic spectrum (FFT) |
| `pcm_lab` | Raw mic PCM read API |
| `sound_deck` | Record / play WAV on SD |
| `portal` | IMU look-around demo |
| `mesh_chat` | BLE Meshtastic chat (needs SenseCAP T1000-E) |
| `settings` | PIN / soft-lock / brightness |
| `squish_id` | Offline catalog + letter pad (sample WRGB thumbs included) |

Other lab apps from the private tree were omitted on purpose.
